{% comment %} character-levels.html — snapshots of a character at different levels, one tab each (newest first, open when the page loads): outfit picture, HP/MP, item level, story quest, every stat, and the actions learned so far plus the next ones coming. Used by character-card.html when the log's character has a "levels:" list (oldest first, one item per snapshot). Stats show how much they went up since the snapshot before, like "+12", so you can see what changed as the character grows. How the tabs work without JavaScript: each tab is a hidden radio button, its label (the tab you tap) and its panel, side by side. Labels line up in a row; panels are pushed onto their own line underneath (see "Level tabs" in reads.css). The checked radio shows its own panel.
