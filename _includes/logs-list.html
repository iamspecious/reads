{% comment %} logs-list.html — the list of every log in one half, with filter buttons. Used by logs/index.html (Books) and games/logs/index.html (Games). Why it works this way: the full list is always in the page. The filter buttons only hide cards. So if JavaScript is off or fails, you still see everything. The buttons start hidden and logs-filter.js shows them, so nobody taps a button that does nothing. The Type buttons only appear when this half has more than one type (Books holds books and shows; Games only games, so it has no Type row). Sort order: most recently started first, because that's usually what you're in the middle of. {% endcomment %} {% include section.html %} {% include section-entries.html %}
